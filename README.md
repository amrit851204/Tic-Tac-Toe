# Tic-Tac-Toe

This is my first mini project: a classic Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features
- 3x3 grid gameplay
- Two-player turn-based gameplay
- Win detection
- Draw detection
- Restart/reset button
- Clean and simple user interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository
2. Open `index.html` in your browser
3. Start playing

## Project Goal
This project was created as a beginner-friendly web development exercise to practice:
- HTML structure
- CSS styling
- JavaScript logic
- DOM manipulation
